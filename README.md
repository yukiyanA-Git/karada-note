# からだの違和感ノート（Karada Note 40+）

40代からの「なんとなく気になる不調・からだの違和感」をサッと記録し、診察時に医師へ伝えたり、匿名で同世代と体験を共有できるWebアプリです。

## 🌐 公式本番URL（公開中）

- **公開URL**: **[https://karada-iwakan-note.web.app](https://karada-iwakan-note.web.app)**
- **Firebase Project**: `yukiyanart-feedback-hub` (Site ID: `karada-iwakan-note`)

## 📱 スマホでのPWA（ホーム画面追加）方法

本アプリはPWA（Progressive Web App）に対応しており、ブラウザからホーム画面に追加することで、通常のスマホアプリと同様に全画面で快適にご利用いただけます。

- **iPhone (Safari)**:
  1. Safariで `https://karada-iwakan-note.web.app` を開く
  2. 画面下部中央の共有ボタン（四角から矢印が出ているアイコン）をタップ
  3. **「ホーム画面に追加」** を選択
- **Android (Chrome)**:
  1. Chromeで `https://karada-iwakan-note.web.app` を開く
  2. 画面右上の「︙」メニューをタップ（または画面下部に現れるインストール案内をタップ）
  3. **「アプリをインストール」** または **「ホーム画面に追加」** を選択

## 🌟 主な機能構成

1. **✍️ 違和感メモ（トップ：3秒クイック入力）**
   - 部位クイック選択（頭、首・肩、腰、背中、目、胃腸、手足、だるさ、その他詳細自由記入）
   - 違和感オノマトペタグ（ズキズキ、重だるい、ピキッとした等）
   - 日時の柔軟指定（現在日時自動、昨夜や数日前への変更も簡単）
   - 最下部に Google AdSense 広告枠（`ca-pub-5012440476019514`）

2. **📊 まいにち測定（日課・日常管理）**
   - 朝・夜・昼の測定タイミング
   - 血圧（上 / 下）・脈拍・体温・体重
   - 処方薬の服薬チェック
   - 服用中のお薬メモ（薬名、目的、処方開始時期、状態管理）
   - 直近7件の血圧手帳風テーブル

3. **📋 じぶんのカルテ（お医者さん提示用）**
   - 違和感タイムライン表示 ＆ 医師向け血圧・バイタル推移表の切替
   - 医師確認用の現在処方薬サマリー
   - 「🩺 医師提示」ボタンで文字を拡大し、診察室で医師にそのまま見せられる画面
   - ※ 診察室での提示を考慮し、広告は完全非表示の清潔な設計

4. **👥 みんなのノート（匿名共有タイムライン）**
   - 都道府県バッジ付きの匿名投稿
   - 受診結果・後日談の追記閲覧
   - 「わかる・お大事に（🍵）」の共感リアクション
   - 最下部に自社アプリ相互送客バナー（Chronos, micro-chat, 攻略ノート, AURAgallery）＆ 森の案内所（Hub）リンク
